# Web_SchoolWork

以小组为单位完成一个网站的设计和建设，网站主题任选，小组内每个成员都要完成一定的工作量，最终作业材料提交由组长统一上传即可。具体要求：

一、采取个人报优方式，每位报优的同学工作量不得少于4个展示页面；使用动态页面技术、数据库技术和其他页面技术进行页面设计的（但不能用框架），有额外加分

二、报优的同学五一之后统一进行课堂答辩，每位报优的同学都需要上台展示自己所作的内容

三、每个同学完成个人主页（页面不限），小组网站要有链接到各位同学个人主页的链接

四、所有的组都需要提交以下三项内容：

    1 小组实验报告（不要放在压缩包中），模板见附件。报告中要明确注明每个成员的学号，姓名，工作量百分比！！

    2 网站演示视频（不要放在压缩包中）。

    3 网站源代码（打包上传）。

五、大作业提交的截至时间为第13周周三（6月3日），建议大家尽量利用课堂时间完成大作业和实验报告，并及时提交！未及时提交作业或小组内工作量为0，则本课程成绩按不及格记录
